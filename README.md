# Stock Opname Frontend

## 1. Clone Repository
```bash
git clone git@github.com:faizabdulchakim/stock_opname_fe.git
```

## 2. Enter Project Folder & Install Dependencies
```bash
cd stock_opname_fe
npm install
```

## 3. Create `.env` in Root Folder
```env
REACT_APP_API_URL=http://localhost:3000/api
PORT=3001
```

## 4. Run FE
```bash
npm start
```

FE runs on port 3001:
- http://localhost:3001

## 5. Running Unit Test
```bash
npm test
```

---

## Tech Stacks
- **Framework:** React.js
- **Unit Test:** Jest & React Testing Library
